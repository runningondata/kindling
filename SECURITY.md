# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.x     | Yes       |

## Reporting a vulnerability

Please report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/allyreilly/kindling/security/advisories/new).

**Do not open a public issue for security vulnerabilities.**

### What to expect

- **Acknowledgement** within 48 hours of your report
- **Status update** within 7 days with an assessment and expected fix timeline
- **Fix or disclosure** within 30 days for confirmed vulnerabilities

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)
